# Image Grid Layout

Implementação do desafio **Image Grid Layout** do [roadmap.sh](https://roadmap.sh/projects/image-grid).

## Sobre o projeto

Este projeto consiste na criação de uma galeria de imagens utilizando **CSS Grid**, com diferentes imagens ocupando diferentes áreas da grade.

O objetivo principal foi praticar a criação e o posicionamento de elementos dentro de uma grid, trabalhando com múltiplas linhas e colunas, além de desenvolver um layout visualmente organizado e responsivo.

## Conceitos praticados

* CSS Grid
* `grid-template-columns`
* `grid-template-rows`
* `grid-row`
* `grid-column`
* `grid-row: span`
* `gap`
* Unidades relativas como `fr` e `vh`
* `object-fit: cover`
* Dimensionamento e posicionamento de elementos
* Estruturação semântica com HTML
* Responsividade do layout

## Estrutura

O projeto utiliza uma estrutura simples:

* **HTML** — estrutura da galeria e elementos de imagem.
* **CSS** — definição da grid, posicionamento dos itens, dimensionamento e apresentação das imagens.
