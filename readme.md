# Roadmap.sh Projects

Este repositório reúne os projetos e desafios que estou desenvolvendo com base nos roteiros de aprendizagem e projetos propostos pelo [roadmap.sh](https://roadmap.sh/).

O objetivo é consolidar, na prática, os conhecimentos adquiridos durante os meus estudos de desenvolvimento web, documentando minha evolução através de projetos reais e exercícios práticos.

## 🎯 Objetivo

Utilizar os desafios do roadmap.sh para:

* Praticar conceitos de desenvolvimento web.
* Transformar conhecimentos teóricos em projetos práticos.
* Desenvolver boas práticas de HTML, CSS e JavaScript.
* Aprender a estruturar e organizar projetos.
* Construir um portfólio de projetos.
* Acompanhar minha evolução como desenvolvedor.
